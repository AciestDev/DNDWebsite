# Better than roll20

## Why 

This is a personal project intended for learning the basics of dynamic web development. Also because I think info should be free. Since you can get access to all dnd material for free, just not use efficiently without paying on dnd beyond, I'll make my own.

## More to come

Currently this is very bare bones and is still in version 0.01. I intend to have a handful of testers when version 0.1 releases and probably a compete overhaul after version 0.5 when I realize I made everything poorly. And at the end of the day this is for fun.
